# แคมป์ไกด์ — คู่มือฟาร์ม Night Camp

เว็บแอปคู่มือฟาร์มที่สร้างจากข้อมูลจริงทั้งหมดของ [วิกิ Night Camp](https://play.nightcamp.app/wiki/) (SS2 v0.2) — อาชีพ 46 อาชีพ, สกิล 443+, อาวุธ 1,427 ชิ้น, มอน 482 ตัว, แมพ 176 แมพ, ชุดเซ็ต 80 เซ็ต, รูน 34 ชนิด

**เปิดใช้งาน:** ดับเบิลคลิก `index.html` ได้เลย (ไม่ต้อง build) หรือ serve ด้วย http server ก็ได้

## ฟีเจอร์

1. **คู่มืออาชีพ** — เลือกอาชีพแล้วได้
   - สายการเล่นแยกตามสกิล/อาวุธ พร้อมอาวุธที่เสริมแต่ละสาย
   - อาวุธที่ใช้ได้ทั้งหมดเรียงตามเลเวล พร้อมมอน+แมพ+เขตที่ดรอป
   - แมพที่ควรฟาร์มแยกช่วงเลเวล 1–99 (จัดอันดับจากเลเวลมอน + คู่ธาตุกับอาวุธที่เลือก)
   - ชุดเซ็ตแนะนำตามสายเกราะ พร้อมตารางมอน/แมพที่ดรอปทุกชิ้น
   - จำลองภาพการฟาร์ม (canvas) ตามเลเวลและธาตุของอาวุธที่เลือก — แสดงมอนที่ได้/เสียเปรียบธาตุ

2. **คลังไอเทม** — อาวุธ / รูนการ์ด / ชุดเซ็ต / เกราะ&อุปกรณ์ / มอน / แมพ
   - ค้นหาได้ทั้งชื่อไทยและรหัส (เช่น `gs_batking`) + ฟิลเตอร์ชนิด/ธาตุ/เขต/บอส
   - แสดงคุณสมบัติครบทุกชิ้น กดดูรายละเอียดได้ (มอนที่ดรอป + แมพ + เขต เช่น ที่ราบสูง)

3. **วางแผนฟาร์ม Lv 1 → 99**
   - เลือกอาชีพหลัก, เลเวลตัวหลัก, จำนวนปาตี้ (สูงสุด 5), อาชีพของสมาชิกทุกคน
   - ถ้าปาตี้มีบิชอป/พรีสต์/มังค์/บาร์ด ฯลฯ จะมีตัวเลือกบัพให้ติ๊กว่าอัพมาแล้ว
   - เลือกเป้าหมาย: เลเวล / ไอเทม / ทั้งคู่ → ได้แผนฟาร์มทีละช่วงเลเวล พร้อม
     EXP/นาที, เวลาโดยประมาณต่อช่วง, รายการไอเทมเป้าหมาย + จำนวนที่ต้องฆ่า

## โครงสร้าง

```
index.html          หน้าเว็บหลัก (SPA 3 หน้า)
css/style.css
js/app.js           ตรรกะทั้งหมด
js/data.js          ข้อมูลที่ประมวลผลแล้ว (สร้างอัตโนมัติ)
data-src/           ข้อมูลดิบจากวิกิ (wiki_en.json + i18n_th.json)
tools/build-data.mjs สคริปต์แปลงข้อมูล + แปลไทย
```

อัปเดตข้อมูล: ดึง `wiki_en.js` และ `i18n_th.js` ใหม่จากวิกิ แปลงเป็น JSON ใส่ `data-src/` แล้วรัน `node tools/build-data.mjs`

## หมายเหตุ
- ตัวเลข EXP/เวลา/อัตราฆ่าในหน้าวางแผนเป็น**การประมาณการ**จากค่า EXP ของมอนในวิกิ + สมมติฐานที่ระบุไว้ในหน้าเครื่องมือ (เกมยังไม่เปิดเผยตารางจริง)
- ตารางคู่ธาตุใช้แบบมาตรฐาน (น้ำ>ไฟ>ดิน>ลม ฯลฯ) เป็นแนวทาง
- การจับคู่อาชีพ↔สายเกราะ (หนัก/แสง/ผ้า/เรนเจอร์) เป็นการจับคู่ตามแนวโน้มของชุดในวิกิ
